# 📈 Ledger – Trading Journal

A modern and open-source trading journal for traders.

## Features

- 📊 Trading Dashboard
- 📈 Equity Curve
- 💹 Win Rate Analytics
- 📅 Trade History
- ✏️ Add/Edit/Delete Trades
- 📉 Drawdown Tracking
- 📊 Monthly Performance
- 📈 Pair Performance Analysis
- 💾 Local Storage Support
- 📱 Responsive Design

## Built With

- HTML5
- CSS3
- JavaScript
- Chart.js
